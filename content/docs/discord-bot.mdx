The Saver Discord bot brings your todos and bookmarks into Discord, so you can save and browse them without leaving a server.

## Getting started

Invite the bot to your server, then link your Saver account with `/settings`. Once linked, you can choose a default space so commands don't need one specified every time.

## Slash commands

| Command | Description |
| --- | --- |
| `/todos [space]` | Browse todos from a space (defaults to your active space). |
| `/bookmarks [space]` | Browse bookmarks from a space (defaults to your active space). |
| `/create todo <text> [space]` | Saves a new todo to a space. |
| `/create bookmark <url> <title> [space]` | Saves a new bookmark to a space. |
| `/settings` | Manage your Saver bot settings, like your default space. |
| `/bot-appearance set` | Customize the bot's nickname, avatar, banner, and bio for the server (Pro). |
| `/help` | Shows info about Saver and useful links. |

## Message actions

Right-click (or long-press on mobile) any message in Discord to:

- **Save to bookmark**: save the message as a bookmark.
- **Save to todo**: save the message as a todo.
- **Save message to selected channel** / **Save message to DMs**: forward a message into Saver.

## Custom bot appearance (Pro)

Servers on the **Pro** plan can customize the bot's nickname, avatar, banner, and bio for that server using `/bot-appearance set`. This requires the "Manage Server" Discord permission. See [Pricing](/pricing).
