Saver for reMarkable brings your synced todos, bookmarks, habits, and spaces to the tablet. 
You can create and edit items, complete todos, log habits, and turn selected handwriting into a Saver todo.

This is the official Saver integration. The tablet layer is an unofficial mod built on the community projects
[xovi](https://github.com/asivery/xovi), [AppLoad](https://github.com/asivery/rm-appload), and [qt-resource-rebuilder](https://github.com/asivery/rm-xovi-extensions).  It is not affiliated with or endorsed by reMarkable.

<Callout title="Developer Mode resets the tablet" type="warn">
  Installation needs root SSH access and runs third-party code inside the
  tablet's main UI process. On Paper Pro, Paper Pro Move, and Paper Pure,
  enabling [Developer Mode](https://developer.remarkable.com/documentation/developer-mode)
  factory-resets the tablet and weakens its security. Sync or back up your data
  before enabling it. reMarkable 1 and 2 do not require that Developer Mode
  step, but the mod is still unofficial and installed at your own risk.
</Callout>

## Compatibility

`saver-remarkable` is published in [Vellum](https://vellum.delivery)'s stable
repository, so installation on a supported device takes two commands and no
build toolchain.

| Device | Build | Core Vellum package | Status |
| --- | --- | --- | --- |
| Paper Pro | aarch64 | Yes | Core tested on reMarkable OS 3.27.3.0 |
| Paper Pro Move | aarch64 | No, build from source | Core untested. Capture blocked by the core dependency |
| Paper Pure | aarch64 | Yes | Core untested. Capture bindings unverified |
| reMarkable 2 | armv7 | Yes | Core tested on OS 3.25.0.142, 3.26.0.68, and 3.27.3.0. QML patches apply on 3.27.3.0 |
| reMarkable 1 | armv7 | Yes | Core untested. Capture bindings unverified |

reMarkable 1 and Paper Pure are expected to run the core app because each uses
an existing build target and the same 1404 x 1872 display size as reMarkable 2.
They have not yet been confirmed on hardware. A **Yes** above only describes
the core package. It does not establish compatibility for handwriting capture.
Paper Pro Move remains excluded because its different display dimensions may
need UI changes. [Build from source](#install-from-source) to try it.

The tested AppLoad version is 0.5.3. Firmware updates can break xovi or the
optional UI patches even when the native app still uses the same build.

`saver-remarkable-capture` additionally requires all of the following:

- reMarkable OS 3.26 or newer and older than 3.28
- `qt-resource-rebuilder` and `qt-command-executor` on that device
- a manual hashtable build after installation

The capture patches bind to private xochitl file paths, component anchors, and
handwriting APIs. These must be checked on every device and firmware release.
The upper bound is a guard for unverified firmware, not a known incompatibility
at 3.28. On OS 3.25 the core app can be installed from source, but the capture
package, sidebar entry, and handwriting action are unavailable.

## Before you start

You need:

- A Saver account and internet access on the tablet. All Saver operations and
  handwriting recognition need internet, normally over Wi-Fi. The USB network
  at `10.11.99.1` does not provide an internet route by itself.
- Root SSH access to the tablet. Paper Pro, Paper Pro Move, and Paper Pure need
  Developer Mode. reMarkable 1 and 2 expose SSH without it.
- [Vellum](https://github.com/vellum-dev/vellum) on the tablet. You can use [reManager](https://github.com/rmitchellscott/reManager) on Linux, macOS, or
  Windows to bootstrap it.

Vellum resolves xovi, AppLoad, and the rest of the dependency chain itself, so
nothing else needs to be installed by hand.

## Install with Vellum

In the commands below, replace `TABLET` with `10.11.99.1` for USB or with the
tablet's Wi-Fi address.

<Steps>
<Step>

**Prepare the tablet**

Connect the tablet over USB, wake it, and confirm that SSH works:

```sh
ssh root@10.11.99.1 true
```

The password appears at the bottom of **Copyrights and Licenses** in the tablet's settings. 
On current Paper Pro software, the full path is
**Settings → General → Help → About → Copyrights and Licenses**.

To install over Wi-Fi on a Paper Pro, Paper Pro Move, or Paper Pure, first
enable Wi-Fi SSH while connected over USB:

```sh
ssh root@10.11.99.1 rm-ssh-over-wlan on
```

</Step>
<Step>

**Install Vellum**

If Vellum is not on the tablet yet, install it with [reManager](https://github.com/rmitchellscott/reManager),
which runs on Linux, macOS, and Windows.

</Step>
<Step>

**Install the Saver app**

```sh
ssh root@TABLET '/home/root/.vellum/bin/vellum add saver-remarkable'
```

</Step>
<Step>

**Optionally add the sidebar entry and handwriting capture**

```sh
ssh root@TABLET '/home/root/.vellum/bin/vellum add saver-remarkable-capture'
```

This pulls in `qt-resource-rebuilder` and `qt-command-executor` automatically.
It refuses to install next to the incompatible `retaskable-capture` or
`convert-to-text-remover` mods, and it needs the one-time hashtable setup in
[Finish the optional UI integration](#finish-the-optional-ui-integration).

</Step>
<Step>

**Restart the tablet UI**

```sh
ssh root@TABLET \
  'setsid bash /home/root/xovi/start >/tmp/xovi-start.log 2>&1 </dev/null &'
```

Saver now appears in the AppLoad launcher. Continue with [Link your Saver account](#link-your-saver-account).

</Step>
</Steps>

## Install from source

<Callout title="Most people don't need this">
  Build from source only to develop on the app, or to run it on a device the
  published package excludes.
</Callout>

Start in a clone of the [saver-remarkable repository](https://github.com/Saver-app/saver-remarkable) and run the commands below from its root. 
You need a macOS or Linux computer with Bash, `ssh`, `scp`, Rust, a GNU Linux
cross-compiler for the tablet, and Qt 6's `rcc` tool. The installer is tested
on macOS. Linux is expected to work but is untested. Native Windows is not
currently documented.

<Steps>
<Step>

**Prepare the tablet**

Enable root SSH access and install Vellum, as described above, then confirm
that SSH works:

```sh
ssh root@10.11.99.1 true
```

The installer automatically tries `~/.ssh/id_remarkable`. Add
`-i ~/.ssh/id_remarkable` to manual `ssh` commands if that key is not already
loaded by SSH.

</Step>
<Step>

**Install the Rust target and cross-linker**

Install the Rust target for your tablet:

```sh
rustup target add aarch64-unknown-linux-gnu      # Paper Pro / Move / Pure
rustup target add armv7-unknown-linux-gnueabihf  # reMarkable 1 / 2
```

You also need the matching GNU Linux compiler. On macOS, [messense's cross-toolchains](https://github.com/messense/homebrew-macos-cross-toolchains)
provide both targets. Configure Cargo in `~/.cargo/config.toml`:

```toml
[target.aarch64-unknown-linux-gnu]
linker = "aarch64-unknown-linux-gnu-gcc"

[target.armv7-unknown-linux-gnueabihf]
linker = "armv7-unknown-linux-gnueabihf-gcc"
```

Use an absolute path if the compiler is not on `PATH`. Debian-based Linux
toolchains commonly name these binaries `aarch64-linux-gnu-gcc` and
`arm-linux-gnueabihf-gcc` instead.

</Step>
<Step>

**Install Qt's resource compiler**

Use your system's Qt 6 package when available. On macOS, you can install only
the required Qt archive:

```sh
python3 -m pip install aqtinstall
python3 -m aqt install-qt mac desktop 6.8.2 clang_64 \
  -O "$HOME/Qt" --archives qtbase
```

The resulting `rcc` is normally at `$HOME/Qt/6.8.2/macos/libexec/rcc`. On Linux, it is often at
`/usr/lib/qt6/libexec/rcc`. Use the path supplied by your Qt package.

</Step>
<Step>

**Build and install Saver**

The installer syntax is `./install-device.sh [host] [target]`. Set `RCC` to
the path from the previous step:

```sh
# Paper Pro / Move / Pure over USB (the default host and target)
RCC=/path/to/rcc ./install-device.sh

# Paper Pro / Move / Pure over Wi-Fi
RCC=/path/to/rcc ./install-device.sh 192.168.1.42

# reMarkable 1 / 2 over USB
RCC=/path/to/rcc ./install-device.sh \
  10.11.99.1 armv7-unknown-linux-gnueabihf
```

Use `SSH_KEY=/path/to/private-key` if your key is somewhere other than
`~/.ssh/id_remarkable`.

The script builds the app, installs missing device components through Vellum,
copies the app and optional UI patches, and restarts the tablet UI through
xovi.

To install only the core AppLoad app, without the sidebar or handwriting
actions:

```sh
SKIP_QMLDIFF=1 RCC=/path/to/rcc ./install-device.sh
```

Use this mode if you have the incompatible `retaskable-capture` or
`convert-to-text-remover` QML mod. It does not remove Saver patches from an
earlier installation. See [Update or remove](https://github.com/Saver-app/saver-remarkable#update-or-remove)
before switching an existing installation to core-only mode.

</Step>
</Steps>

## Finish the optional UI integration

Either installation path needs this once, and only for the sidebar and
handwriting actions. `qt-resource-rebuilder` needs a one-time hashtable build
on the tablet. If the installer reports that the hashtable is missing, or if
the sidebar entry does not appear after installing `saver-remarkable-capture`,
run:

```sh
ssh root@TABLET /home/root/xovi/rebuild_hashtable
```

This restarts the tablet UI and may ask for the device passcode. Afterwards,
restart the UI through `/home/root/xovi/start` (Vellum install) or run the
installer once more (source install) so the sidebar and selection-menu patches
are applied.

## Link your Saver account

1. Make sure the tablet is connected to Wi-Fi.
2. Open **Saver** from the file-browser sidebar or the AppLoad launcher.
3. Scan the QR code with another device. Alternatively, open the
   [Saver web app](https://app.saver-app.com), go to **Settings → reMarkable tablet → Enter code from tablet**, 
   and enter the 8-character code shown on the tablet.
4. Approve the connection. The tablet finishes linking and loads your spaces
   and items automatically.

Pairing codes expire after 10 minutes. Changes made in Saver on another device
appear when the tablet app opens or when you tap **Refresh**. There is no
background sync or persistent offline cache on the tablet.

## Capture a handwritten todo

Handwriting capture uses reMarkable's handwriting-recognition service. The
tablet must be online, signed in to a reMarkable account, and have
`saver-remarkable-capture` (or the equivalent source-built QML patches)
installed.

1. Select handwritten strokes with the notebook lasso tool.
2. Tap the Saver checkmark action in the selection menu.
3. Review the recognized text and choose a Saver space/list, or save directly
   with the defaults under **Saver → Settings**.
4. Optionally tap **Reminder** to choose a date, time, and repeating weekdays.
   Reminders are available when the review dialog is shown. Keep **Ask before
   saving handwritten todos** enabled in Saver settings if you want this step.

## Update Saver

To update a Vellum installation, upgrade and restart the tablet UI:

```sh
ssh root@TABLET '/home/root/.vellum/bin/vellum upgrade'
ssh root@TABLET \
  'setsid bash /home/root/xovi/start >/tmp/xovi-start.log 2>&1 </dev/null &'
```

To update a source installation, pull the latest code and rerun the same
`install-device.sh` command. Either way, close and reopen Saver after the
tablet UI has restarted.

## Troubleshooting

- **Pairing or refresh cannot reach Saver:** connect the tablet itself to
  Wi-Fi. USB networking supports installation but does not provide internet.
- **Paper Pro family Wi-Fi installation cannot connect:** enable it over USB with
  `ssh root@10.11.99.1 rm-ssh-over-wlan on`, then retry with the tablet's
  Wi-Fi address.
- **`vellum add` cannot find the package:** refresh the index with
  `vellum update`. If it is still missing, your device or OS version is one the
  package excludes, see [Compatibility](#compatibility), and you need a source
  build.
- **The sidebar or handwriting action is missing:** check that
  `saver-remarkable-capture` is installed, rebuild the hashtable, restart the
  UI, and check for `retaskable-capture`, `convert-to-text-remover`, or a
  firmware/QML-patch mismatch.
- **A reinstall appears unchanged:** close Saver completely and reopen it from
  AppLoad.
- **Saver opens and immediately closes:** collect recent device logs with:

```sh
ssh root@TABLET \
  "journalctl -u xochitl --since '-5min' --no-pager | tail -n 200"
```

For advanced diagnostics, removal instructions, security details, and
development notes, see the [Saver for reMarkable README](https://github.com/Saver-app/saver-remarkable#readme).
